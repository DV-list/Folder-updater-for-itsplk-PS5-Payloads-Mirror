# Folder updater v1.9.5

## Release highlights

- Update the application and GUI window title to version **1.9.5**.
- Build and test platform-specific packages for Windows x64, macOS, and Linux x64 through GitHub Actions.
- Publish the three platform packages as assets on this GitHub Release.

## Downloads

- **Windows x64:** standalone `.exe`
- **macOS:** `.zip` containing the `.app` bundle
- **Linux x64:** `.zip` containing the native executable

## Notes

Builds are produced on their respective operating systems; PyInstaller is not a cross-compiler. Please report OS-specific launch or runtime issues with the operating system version and the relevant `appdata/application.log` details.
